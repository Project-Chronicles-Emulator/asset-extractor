# Contributing

Keep changes focused, preserve upstream notices and document the supported input/build.
Run the standalone build and available offline checks. State separately whether a real
local client/snapshot was tested. Build success is not a compatibility claim.

Do not commit client files, generated game SDKs, dumps, assets, captures, local
archive-key files, other client-build keys, dependency binaries or credentials.
The October 23, 2026 demo key is intentionally documented in the README.
Use sanitized reproductions and synthetic tests.
